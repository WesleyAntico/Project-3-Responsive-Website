# NYC Landmarks — Site Map

## Pages

All HTML pages are in the same folder. The home page links to each landmark page.

| Page | Filename |
| --- | --- |
| Home | `index.html` |
| Statue of Liberty | `liberty.html` |
| Empire State Building | `empire.html` |
| Staten Island Ferry | `ferry.html` |
| Wonder Wheel / Coney Island | `coney.html` |

## Page content

- **Home:** 
    - Introduction
    - embedded video
    - featured landmark
    - six landmark cards linking to their pages.
- **Coney Island:**
    - Wonder Wheel image with photo credit
    - Coney Island description.
- **Landmark pages:** 
    - Landmark name
    - introduction
    - credited hero image
    - About section with Built and Today text
    - More Info links
    - Directions
    - Previous/Next links, cycling through the six landmark pages.
- **Every page:** 
    - Shared header element with site name and navigation
    - main element with page-specific content
    - Shared footer element.

## Navigation

The home page is outside the landmark sequence. Previous/Next links follow this loop:

Statue of Liberty → Empire State Building → Staten Island Ferry → Coney Island → Yankee Stadium → Roosevelt Island Tramway → Statue of Liberty

Use the filenames above as relative link destinations.
